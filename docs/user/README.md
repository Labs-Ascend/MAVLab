# MAVLab User Guide

Use MAVLab v1.6.1 to fly a simulated quadcopter on Android, inspect its telemetry and 3D model, or connect QGroundControl to run supported missions.

## Get started

1. [Install MAVLab](../setup_guide.md) or [check upgrade instructions](upgrading.md).
2. [Fly locally on Android](first-flight.md).
3. [Explore the four views](navigation-and-display.md).
4. [Connect QGroundControl](connect-qgroundcontrol.md) on the same phone or a desktop.
5. [Upload and run a mission](mission.md) when you want autonomous flight.

See [onboarding](onboarding.md) to replay the introduction and [first-run troubleshooting](../known_first_run_issues.md) for connection or installation problems.

## Screen reference

| View | Use it for |
| --- | --- |
| [Cockpit](cockpit.md) | Live telemetry, flight mode, control authority, and immediate actions. |
| [Control](controller.md) | Calibration, local input, flight actions, and received mission controls. |
| [SIM](sim.md) | Engine-driven 3D vehicle, received route, and observed trail. |
| [Ops](ops.md) | Runtime health, connections, mission transfer details, failure scenarios, and recordings. |
